## Questions

Q1. What is the output of `print(len(("apple", "banana", "cherry")))`? 

Q2. What is the output of `print([10, 20, 30, 40][-2])`?

Q3. State whether a list and a tuple behave the same way when you try to change an element after creation. Justify in one line. 

Q4. What is the output of `print({1, 2, 2, 3, 3, 3})`? 

Q5. Write a program to reverse a given string without using slicing (`[::-1]`) or any built-in reverse function.

Q6. Write a program to count the frequency of each word in a given sentence using a dictionary. 

Q7. Write a program to remove duplicate elements from a list without using the `set()` function. 

Q8. Write a program to find the second largest element in a list without using the `sort()` or `max()` functions. 

Q9. Design a program that stores student names and their marks in a dictionary, finds the topper, and displays the result. Justify the approach you used to find the topper. 

Q10. Create a program that takes a paragraph as input and counts the number of vowels, consonants, digits, and spaces in it using suitable data structures. Analyze how the program's performance would be affected for a very large paragraph.
